# tmpx Feedback

This file is a lightweight bucket for adopter feedback during beta.

## What to report
- Missing high-frequency tags (with concrete examples)
- Ergonomics pain points (`_parts/_attrs` verbosity)
- Migration friction (tmpx -> tmpx)
- Determinism/safety bugs (escaping, attr ordering)

## Out of scope (for now)
- svg / canvas / script / style
- Large macro syntax redesign

## Request format
- Use case snippet
- Expected output
- Current workaround (if any)
